메모리(저장 장치) 안에서 직접 계산해 데이터 이동 낭비를 없애고, 최대 30%의 부품 오류에도 결과가 망가지지 않는 인공지능용 반도체 계산 방식을 제안했다.

**무엇이 문제였나** — 기존 컴퓨터는 데이터를 저장 장치와 연산 장치 사이로 끊임없이 옮겨야 해서 전력 소모가 컸고, 작은 전기적 오류에도 전체 결과가 왜곡되기 쉬웠습니다.
**어떻게 풀었나** — 이 기술은 숫자를 0과 1이 고르게 섞인 긴 띠(비트열) 형태로 표현하여 저장 장치 내부의 간단한 자성 회로로 사칙연산과 비교 연산을 직접 수행합니다.
**그래서 뭐가 좋아졌나** — 극한의 소자 잡음이나 전압 강하 조건에서도 이미지 복원 작업을 안정적으로 처리하며, 기존 컴퓨터 대비 약 10배의 에너지 절감 효과를 보였습니다.

> 중요한 숫자를 하나의 장부에 적어두면 잉크 한 방울만 번져도 숫자가 완전히 바뀌지만, 100장의 투표용지에 찬반 표를 던져 비율로 숫자를 표현하면 몇 장에 오타가 나거나 찢어져도 전체 찬성 비율(원래 값)은 거의 변하지 않는 것과 같습니다.

## 논문 정보

Farzad Razi, Mehran Moghadam, Sercan Aygun, M. Hassan Najafi, Marc Riedel · University of Minnesota; Case Western Reserve University; University of Louisiana at Lafayette · 본문에 발표 학회 또는 저널이 명시되지 않음 (arXiv:2609.00701v1) · 2026

## 왜 중요한가

스마트폰이나 자율주행 차량, 웨어러블 센서처럼 배터리가 제한되고 거친 외부 환경에서 작동해야 하는 엣지 기기에서는 전력 절감과 고장 내성이 필수입니다. FALCON은 복잡한 난수 생성기 없이도 메모리 내부에서 오류에 강한 연산을 직접 끝냄으로써 초저전력·고신뢰성 AI 구동을 가능하게 합니다.

## 핵심 지표

| 지표 | 값 | 설명 |
|---|---|---|
| 최대 soft error 주입률 | **30%** | 소프트 에러 및 소자 노이즈가 30%까지 주입되어도 연산 기능 정상 유지 |
| 실루엣 closing IoU (FALCON) | **0.89** | 30% 소자 노이즈 환경에서 이상적 마스크와의 형상 일치도 (기존 binary는 0.64) |
| 256×256 closing 실행 에너지 | **7.63µJ** | 256×256 영상의 in-situ morphological closing 수행 시 소모된 총 회로 에너지 |
| 0.7V 전압 스케일링 전력 절감 | **51%** | 0.9V 대비 0.7V로 공급 전압 스케일링 시 정확도 손실 없이 달성한 전력 절감률 |

## 어떻게 동작하나

FALCON은 n비트 2진수 입력 X의 각 비트 Xi를 2^i번 복제하고 저불일치(low-discrepancy, LD) 패턴에 배치하여 길이 N=2^n 비트열을 결정론적으로 생성한다. 동일한 LD 패턴은 min/max/절댓값 차에 필요한 완전 상관 입력을 형성하고, 서로 다른 LD 패턴은 곱셈과 스케일 덧셈에 필요한 비상관 입력을 형성하여 기존 SC의 난수 생성기(RNG)와 스위칭 확률 보정 회로를 완전히 제거한다. MTJ 기반 로직-인-메모리(LIM) 셀은 저항 상태(HH, HL, LH, LL) 설정 후 기준 MTJ와의 전압 분배 감지를 통해 AND/NAND, OR/NOR, XOR, MUX 기본 논리를 재구성 가능하게 수행하며, 이를 통해 곱셈(AND), 최솟값(AND), 최댓값(OR), 절댓값 차(XOR), 스케일 덧셈(MUX), 나눗셈(MUX 피드백)의 전체 산술 연산 스위트를 메모리 내부에서 실행한다. 출력 비트열은 후속 연산에 직접 재사용되거나 LIM 기반 변환기를 거쳐 O(log2 N) 단계 만에 2진수로 복원된다. 검증은 14 nm FinFET 기반 HSPICE 과도 응답 시뮬레이션, 최대 30% soft error 주입, ±3σ Gaussian 10% 공정 변동(FinFET 및 MTJ 주요 파라미터), 0.9/0.8/0.7 V 공급 전압 스케일링 환경에서 수행되었다. 응용 사례로 3×3 dilation과 erosion으로 구성된 morphological closing을 256×256 grayscale 및 binary 영상에 적용하고 salt-and-pepper 15%와 소자 노이즈 30% 조건에서 평가했다.

핵심 수식:

```
P_X = X / 2^n = X / N  (N = 2^n)
곱셈(X × Y): z_i = x_i ∧ y_i  (비상관 스트림, 서로 다른 LD 패턴)
스케일 덧셈((X + Y) / 2): z_i = MUX(x_i, y_i; w_i), P_W = 0.5  (비상관 제어 스트림)
최솟값(min(X, Y)): z_i = x_i ∧ y_i  (상관 스트림, 동일 LD 패턴)
최댓값(max(X, Y)): z_i = x_i ∨ y_i  (상관 스트림, 동일 LD 패턴)
절댓값 차(|X - Y|): z_i = x_i ⊕ y_i  (상관 스트림, 동일 LD 패턴)
나눗셈(X / Y): MUX 피드백 루프 기반 연산
```

n비트 입력 X의 각 가중치 비트 X_i를 2^i번 복제하여 길이 N=2^n인 비트열을 구성하므로, 비트열 내 '1'의 비율은 정규화된 값 P_X = X/2^n(또는 X/N)과 수학적으로 정확히 일치한다. 동일한 LD 패턴을 부여하면 완전 상관 스트림이 되어 min, max, 절댓값 차 연산이 가능하고, 서로 다른 LD 패턴을 부여하면 비상관 스트림이 되어 AND 게이트 기반 곱셈 및 MUX 기반 스케일 덧셈·나눗셈을 수행한다.

## 한계와 주의할 점

- 검증은 14 nm FinFET 기반 회로 수준 HSPICE 시뮬레이션과 3×3 morphological closing 단일 사례에 집중되어 있으며, 실제 테이프아웃된 실리콘 칩 실측 데이터나 대규모 심층신경망(DNN) 추론 워크로드에 대한 평가는 부족하다.
- 비트열을 사이클당 1비트씩 직렬 처리하므로 연산 지연시간이 비트열 길이 N에 선형 비례(O(N))하여, 높은 수치 정밀도가 요구되는 응용에서는 N이 커짐에 따라 지연과 버퍼링 오버헤드가 급증할 수 있다.
- Monte Carlo 공정 변동 및 전압 스케일링에서 기능적 정상 동작과 전력 절감을 확인했으나, 통계적 수율(yield)이나 대규모 어레이 집적 시 발생할 수 있는 sneak path 및 기생 저항 영향에 대한 분석이 생략되어 있다.
- 약 10×의 에너지 절감 수치는 256×256 closing의 회로 추출값(7.63 µJ)과 폰 노이만 슬라이딩 윈도우 추정 모델을 비교한 결과로, 실제 시스템 레벨의 I/O 패드 및 컨트롤러 전력 소모를 완전히 포괄한 직접 측정치는 아니다.
- 비트열 길이가 짧은 설정(N=16 등)이나 과도한 오류율 조건에서는 통계적 확률 왜곡이 누적되어 허용 불가능한 수준의 수치 오차가 발생할 수 있다.
- 연산 종류에 부합하지 않는 잘못된 LD 패턴 할당 시 비트열 간 상관관계가 왜곡되어 min/max, 절댓값 차, 곱셈 연산 결과가 크게 변질될 위험이 있다.
- 지연시간 제약이 매우 엄격한 실시간 엣지 제어 워크로드에서는 N 사이클에 걸친 순차 비트 처리 지연을 감당하기 어려울 수 있다.

## 시스템 적용 아이디어

논문의 기법을 비슷한 구조를 가진 시스템에 옮길 때의 적용 지점이다.

### 연산별 LD 패턴 선택기를 LIM 입력 경로에 추가

FALCON의 결정적 bit mapping은 동일 패턴으로 완전 상관 스트림을, 서로 다른 패턴으로 비상관 스트림을 생성한다. 연산 디스패처에 제어 로직을 통합하여 min/max/XOR 연산 시 동일 패턴을, 곱셈 시 상이한 패턴을 자동 할당하도록 회로를 구성하여 상관관계 설정 오류를 원천 차단한다.

**적용 지점** — 인메모리 산술 연산 디스패처와 비트열 인코더

**기대 효과** — 논문은 연산별 상관관계 제어를 제시하지만, 자동 선택기의 오류 감소 수치는 보고하지 않는다.

### 오류율과 지연 예산에 따른 동적 비트열 길이(N) 스케줄러

FALCON 평가에서 비트열 길이가 16, 64, 256, 1024로 증가함에 따라 MAE가 현저히 감소함이 입증되었다(N=1024 무주입 MAE 0.86~1.54%, N=16 MAE 6.97~12.2%). 작업의 지연 예산이 촉박한 경우 짧은 스트림을 배정하고 고정밀 복원이 요구되는 경우 긴 스트림을 선택하는 적응형 스케줄러를 적용한다.

**적용 지점** — 인메모리 비트열 연산 스케줄러

**기대 효과** — 논문 표 1 기준 N=1024에서 30% 노이즈 주입 시 MAE 10.1~17.8%를 유지하며, 지연이 급할 경우 N=64(사이클 16배 단축)로 운용 가능하다.

### 스트림 출력의 단계별 정확도 점검 지점 추가

FALCON은 출력 비트열을 후속 연산에 직접 재사용하거나 LIM 기반 2진 디코더로 되돌릴 수 있다. 복합 연산 파이프라인에서 중요 경계마다 디코더를 배치해 수치 일탈 여부를 검사하고, 임계치를 벗어날 경우 해당 연산 단계를 재수행하거나 스트림 길이를 동적으로 상향 조정한다.

**적용 지점** — 연속 stochastic 연산 파이프라인의 중간 결과 경계

**기대 효과** — 논문은 스트림 재사용과 이진 변환을 지원하지만, 중간 검증에 따른 정확도 향상 수치는 보고하지 않는다.
