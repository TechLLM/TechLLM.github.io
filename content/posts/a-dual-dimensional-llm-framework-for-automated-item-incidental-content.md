시험 문제가 서로 얼마나 비슷한지 문장 형태와 의미로 나누어 평가하고, 비슷한 문제가 중복 출제되지 않도록 제어하는 AI 평가 틀을 제안한 연구다.

**무엇이 문제였나** — 기존 단어 일치 방식은 문장의 짜임새나 깊은 문맥적 의미가 겹치는 문제를 제대로 가려내지 못했다.
**어떻게 풀었나** — AI(LLM)가 문제 쌍의 문장 구조와 의미적 맥락을 2차원으로 분리 평가하여 비슷한 문제끼리 정밀하게 묶었다.
**그래서 뭐가 좋아졌나** — 이 점수를 맞춤형 시험(CAT) 문제 선택에 반영하면 문제 다양성을 확보하면서도 실력 추정의 치우침(편향)을 줄일 수 있다.

> 옷장을 정리할 때 옷의 색깔만 보고 분류하면 셔츠와 바지가 뒤섞일 수 있다. 이 연구는 옷의 형태(셔츠인지 바지인지)와 입는 상황(운동복인지 정장인지)을 따로 따져서 비슷한 옷이 한꺼번에 골라지지 않도록 조절하는 것과 같다.

## 논문 정보

Jing Huang, Jihong Zhang, Hua-Hua Chang · Purdue University; University of Arkansas · arXiv preprint arXiv:2608.24825v1 · 2026

## 왜 중요한가

대규모 시험이나 문제 자동 생성(AIG)에서 상황이나 표현이 유사한 문제가 반복 출제되면 수험자가 피로를 느끼고 시험 공정성이 저해된다. 이 프레임워크는 문제의 표면 표현과 실제 의미를 체계적으로 진단해 시험의 질과 응시 경험을 동시에 보호한다.

## 핵심 지표

| 지표 | 값 | 설명 |
|---|---|---|
| 잔차 상관과의 Spearman 상관 | **0.50r** | LLM 유사도 점수와 GRM 잔차 상관 간 연관 (BLEU: -0.10, Cosine: 0.06) |
| 구조-의미 차원 간 상관 | **0.66r** | 구조적 분해(S1)와 의미적 관련성(S2) 간 Spearman 순위 상관 |
| CAT 평균 Bias (vs MFI) | **0.029 vs 0.033** | LLM 제약 SC-MFI와 비제약 MFI의 능력 추정 평균 편향 |
| CAT 평균 RMSE (vs MFI) | **0.115 vs 0.106** | LLM 제약 SC-MFI와 비제약 MFI의 능력 추정 평균 RMSE |

## 어떻게 동작하나

연구는 구성 개념과 무관하지만 문항 제시 방식에 영향을 미치는 부수적 내용을 구조적 분해(S1: 문항 형식, 문장 구조, 어휘 중복)와 의미적 관련성(S2: 주제 맥락, 일반 어휘 의미, 감정 함축)의 2차원으로 정의한다. Claude Sonnet 4(온도 0) API를 활용해 36개 ECR 문항 쌍에 대해 각 차원의 3개 하위 요소를 0~10점(차원당 총점 0~30점)으로 평가하게 했으며, BLEU와 코사인 유사도를 프롬프트 내 보조 신호(auxiliary signal)로 제공했다. 최종 유사도 행렬은 가중치 w1=0.3, w2=0.7로 결합한 후 정규화 거리 행렬로 변환하여 계층적 군집화를 수행했다(4개 군집 형성). 타당성 검증에는 35,278명의 ECR 응답에 적합한 graded response model(GRM)의 잔차 상관(Spearman 순위 상관) 및 문항 모수를 사용했으며, 군집 간 GRM 임계치 차이를 MANOVA로 검증했다(F(12, 93)=4.79, p<.001). CAT 시뮬레이션은 50회 반복(반복당 2,000명, 시험 길이 20문항)으로 수행되었으며, 2단계 문항 선택과 최대우선순위지수(MPI)를 통해 군집별 선택 하한 3문항·상한 10문항을 제약으로 둔 SC-MFI를 비교 평가했다.

핵심 수식:

```
S_{ij}=w_1S_{1ij}+w_2S_{2ij},\quad w_1+w_2=1\nD_{ij}=1-\frac{S_{ij}-\min(S)}{\max(S)-\min(S)}
```

S_{ij}는 문항 i와 j의 결합 유사도, S_{1ij}는 구조적 분해 유사도(형식·문장구조·어휘), S_{2ij}는 의미적 관련성 유사도(주제·의미·정서)이며, w1과 w2는 영역별 가중치(w1+w2=1)다. D_{ij}는 계층적 군집화를 위한 최소-최대 정규화 거리로, 유사도가 커질수록 거리는 0에 가까워진다.

## 한계와 주의할 점

- 검증은 단일 LLM인 Claude Sonnet 4와 단일 문항 은행인 ECR 36개 문항에 한정되어 있어, 다른 모델·언어·시험 분야에서 같은 결과가 나오는지 확인되지 않았다.
- 차원별 평가 프롬프트와 가중치(0.3, 0.7)는 이론적 고려를 바탕으로 정했으며, 가중치나 프롬프트 설계가 달라질 때 결과가 얼마나 바뀌는지 검증하지 않았다.
- 문항 쌍마다 LLM 평가와 설명을 생성하므로 문항 은행이 커질수록 계산량과 API 비용이 커질 수 있다. 본문은 처리 지연이나 비용의 정량값을 보고하지 않는다.
- CAT 평가는 시뮬레이션이며, 시험 응시자의 실제 피로도·경험 개선이나 운영 환경의 효과를 직접 측정하지 않았다.
- 잔차 상관은 부수적 유사성 외에도 testlet 효과와 표본 변동을 반영할 수 있어, 유사성의 완전한 정답 기준으로 보기 어렵다.
- 문항이 짧거나 맥락이 부족하면 LLM이 공유 상황이나 정서를 과잉 해석해 의미 유사도를 잘못 매길 수 있다.
- 같은 형식과 문장 틀을 공유하지만 실제로는 의도적으로 다양한 내용을 다루는 문항이 구조적 유사성 때문에 한 군집에 몰릴 수 있다.
- 프롬프트, 모델 버전, 평가 기준이 바뀌면 점수와 군집이 달라져 문항 은행의 평가가 일관되지 않을 수 있다.
- 유사도 제약이 강하거나 문항 풀이 작으면 능력 추정에 유용한 문항 선택이 제한되어 RMSE가 높아질 수 있다.

## 시스템 적용 아이디어

논문의 기법을 비슷한 구조를 가진 시스템에 옮길 때의 적용 지점이다.

### 문항 은행에 S1·S2 분리 점수와 근거를 저장

문항 은행의 등록·수정 단계에 논문의 dual-dimensional AISA를 적용한다. 문항 쌍마다 구조적 분해(S1)와 의미적 관련성(S2)을 각각 계산하고, 각 차원 점수와 짧은 근거를 함께 저장한다. 가중 결합 점수만 남기는 대신 두 점수를 모두 보관하면, 문항 검토자는 표현 반복과 소재 반복을 구별해 확인할 수 있다. 프롬프트와 모델 버전도 결과에 연결해 재평가 시 비교할 수 있게 한다.

**적용 지점** — 문항 은행의 신규 문항 등록·중복 진단 단계

**기대 효과** — LLM 총점은 잔차 상관과 Spearman r=0.50을 보였고, BLEU는 r=-0.10, cosine은 r=0.06이었다.

### 유사도 군집을 CAT 문항 선택의 제약으로 연결

CAT의 능력 추정 기반 문항 선택 단계에 논문의 similarity-based clustering과 SC-MFI 방식을 적용한다. 문항 유사도 행렬을 거리 행렬로 변환하고 군집을 만든 뒤, 군집별 하한·상한을 선택 제약으로 둔다. 논문 실험에서는 군집당 하한 3문항, 상한 10문항을 설정했으므로 실제 적용에서는 문항 은행 크기와 시험 길이에 맞춰 시뮬레이션으로 경계를 정한다. 운영 중에는 bias와 RMSE를 함께 관찰한다.

**적용 지점** — CAT의 적응형 문항 선택 단계

**기대 효과** — 실험의 평균 bias는 LLM 제약 SC-MFI 0.029, MFI 0.033이었다. 평균 RMSE는 각각 0.115, 0.106으로, bias 감소와 RMSE 증가가 함께 보고됐다.

### 구조·의미 점수 차이가 큰 문항 쌍을 검토 대기열로 분류

문항 은행 진단 도구에 S1과 S2 점수 차이를 이용한 검토 목록을 추가한다. 논문은 대부분의 문항 쌍에서 두 점수 차이가 [-5,5] 범위에 있었고, 차이가 큰 사례에서는 비슷한 문장 틀과 다른 의미가 함께 나타날 수 있음을 설명했다. 따라서 두 점수 모두 높은 쌍, 구조 점수만 높은 쌍, 의미 점수만 높은 쌍을 구별해 검토 화면에 표시한다. 이 목록을 통해 템플릿 반복과 맥락 중복을 각각 확인한다.

**적용 지점** — 문항 유사도 진단 결과의 전문가 검토 단계

**기대 효과** — 논문은 36개 ECR 문항에서 S1과 S2의 Spearman 상관 r=0.66을 보고했으며, 두 차원이 관련되지만 서로 구분되는 정보를 담을 수 있음을 보였다.

## 단계별 도입 로드맵

| 단계 | 목표 | 액션 | 기대 효과 |
|---|---|---|---|
| Phase 1 | 문항 유사도 평가의 기준과 재현성 확인 | 대상 문항 은행의 문항 쌍을 추출하고 S1·S2 평가 프롬프트와 가중치를 명시한다. 전문가가 검토한 표본과 비교해 오판 유형을 기록하고, 모델·프롬프트·점수 설명을 함께 저장한다. | 자동 분석을 적용할 문항 유형과 검토가 필요한 사례를 파악한다. |
| Phase 2 | 문항 은행 진단과 군집 제약을 오프라인으로 검증 | 전체 문항의 유사도 행렬과 군집을 생성해 기존 BLEU·cosine 결과 및 심리측정 지표와 비교한다. 문항 선택 시뮬레이션으로 군집 하한·상한이 편향과 RMSE에 미치는 영향을 평가한다. | 다양성 제약과 측정 정밀도 사이의 운영 기준을 정한다. |
| Phase 3 | 운영 환경에 단계적으로 적용하고 성능 감시 | 검증된 문항 은행과 시험에서 유사도 점수를 선택 과정의 보조 제약으로 적용한다. 선택 기록과 추정 결과를 점검하고, 새 문항 추가나 모델 변경 때 유사도 행렬과 군집을 다시 산출한다. | 반복 노출을 관리하면서 문항 선택의 안정성을 지속적으로 확인한다. |
