여러 에이전트가 함께 배우는 중에 규칙이 바뀌면, 보상 점수의 흐름만 보고 ‘이제 상황이 달라졌다’고 알려주는 감시 방법이다.

**무엇이 문제였나** — 여러 에이전트가 같이 훈련되면, 중간에 목표나 보상 방식이 바뀌어 예전에 배운 행동이 더 이상 맞지 않을 수 있다.
**어떻게 풀었나** — PPR은 매 에피소드의 보상 합계를 부드럽게 만든 뒤, 최근 변화가 커졌는지 보고, 최근 구간과 이전 구간의 모양이 다른지 통계적으로 비교한다.
**그래서 뭐가 좋아졌나** — 가장 빠른 방법은 아니지만, 같은 변화를 여러 번 울리는 불필요한 경보를 크게 줄여 실제 훈련 감시에 더 적합한 신호를 만든다.

> 매일 매출을 보며 가게 운영 방식이 바뀐 시점을 찾는 일과 비슷하다. 하루하루의 흔들림은 평균으로 줄이고, 최근 추세가 갑자기 달라졌는지 확인한 뒤, 이전 기간과 최근 기간이 정말 다른지 비교한다.

## 논문 정보

Fatemeh Saberi Khomami, Julita Vassileva · University of Saskatchewan, Department of Computer Science · arXiv preprint (arXiv:2609.05298v1) · 2026

## 왜 중요한가

스스로 학습하는 협업 시스템은 환경이 바뀌었는지 먼저 알아야 이후에 다시 탐색하거나 재학습할 수 있다. 이 논문은 학습 알고리즘을 고치지 않고 보상 기록만 읽어서 변화 신호를 만들 수 있음을 보여준다.

## 핵심 지표

| 지표 | 값 | 설명 |
|---|---|---|
| PPR 감지 지연 (보상 함수 변화) | **250.7 ± 196.1에피소드** | 실제 변화 시점 episode 20,000 이후 첫 알람까지의 지연, seeds 25-27 평균 ± 표준편차 |
| PPR 사전 오알람 (보상 함수 변화) | **10.7 ± 4.6회** | 실제 변화 이전에 발생한 알람 수, 낮을수록 안정적 |
| PPR 사후 반복 알람 (보상 함수 변화) | **11.0 ± 3.0회** | 첫 post-shift 검출 이후 추가로 발생한 알람 수, 낮을수록 사용 부담이 작음 |
| SMA+KSWIN 사전 오알람 (보상 함수 변화) | **298.3 ± 6.7회** | PPR보다 빨리 감지하지만 변화 전 알람이 매우 많은 baseline 결과 |

## 어떻게 동작하나

PPR은 학습 알고리즘을 수정하지 않고 에피소드 종료 시점의 episodic return 스트림만 읽는 외부 감지기다. 1단계 SMA는 윈도우 w=8로 최근 return을 평균내 단기 잡음을 줄인다. 2단계 EMV는 인접한 평활 return의 차이 제곱을 β=2/3로 지수가중 누적해 변화가 큰 구간을 양의 변동 신호로 바꾼다. 3단계 KSWIN은 최근 테스트 창 m=10과 그 이전 KSWIN 창 W=25의 참조 샘플을 KS 통계량으로 비교하고, α=2×10^-4에서 D > sqrt(-ln(alpha)/m)이면 drift로 표시한다. 실험은 MADDPG로 학습한 custom Speaker-Listener 환경에서 수행되며, reward-function-change와 landmark-colour-change 두 shift를 episode 20,000에 주입한다.

핵심 수식:

```
R̄_e = (1/w) Σ_{i=e-w+1}^{e} R_i ;   V_e = β(R̄_e - R̄_{e-1})² + (1-β)V_{e-1} ;   D = sup_x |F_A(x) - F_B(x)| ;   τ_α = sqrt(-ln(α)/m)
```

R_e는 episode e의 return, R̄_e는 윈도우 크기 w의 단순이동평균, V_e는 평활 return의 최근 변화량을 누적한 EMV 신호다. B는 크기 m의 최근 테스트 창, A는 그 이전 KSWIN window W에서 뽑은 참조 샘플이며, D가 임계값 τ_α보다 크면 episode e 이후 drift indicator d_e=1로 표시한다.

## 한계와 주의할 점

- 실험 seed가 각 시나리오 3개뿐이라 평균과 표준편차의 신뢰도가 제한적이다.
- 보상 함수 변화 시나리오에서 PPR의 감지 지연 표준편차가 196.1로 평균 250.7에 비해 커서 학습 궤적에 민감하다.
- 평가 환경이 custom Speaker-Listener 하나와 두 개의 통제 shift에 한정되어 더 큰 규모의 MARL, 다른 알고리즘, 실제 도메인으로의 일반화는 아직 검증되지 않았다.
- 보상 기반 감지기이므로 변화가 episodic return에 약하게만 나타나면 탐지가 늦거나 어려울 수 있다.
- β와 w에 따른 민감도가 크다. Table 3에서 β=0.5는 더 빠르지만 사전·사후 알람을 크게 늘리고, β=1.0은 0/3 검출로 실패했다.
- 논문은 변화 감지까지 다루며, 감지 후 replay buffer 조정, 정책 복구, 재학습 같은 적응 절차는 후속 과제로 남긴다.
- Raw return + KSWIN은 reward-function-change에서 1/3 run만 검출했고, 검출된 경우도 지연이 18424.0 episode로 매우 늦었다.
- Raw return + KSWIN은 landmark-colour-change에서도 1/3 run만 검출했으며, 검출 지연은 4178.0 episode였다.
- SMA + KSWIN은 빠르게 감지하지만 reward-function-change에서 사전 알람 298.3 ± 6.7회, 사후 반복 알람 286.3 ± 17.6회를 내 실사용 알람으로는 불안정하다.
- β=1.0 설정은 landmark-colour-change 민감도 실험에서 post-shift 검출이 0/3으로 실패했다.
- w=10은 landmark-colour-change에서 사전·사후 알람을 낮추지만 detection delay를 1100.3 ± 697.1 episode까지 늘렸다.

## 시스템 적용 아이디어

논문의 기법을 비슷한 구조를 가진 시스템에 옮길 때의 적용 지점이다.

### 에피소드 보상 흐름을 감시하는 PPR식 드리프트 워치독을 학습 루프에 부착

매 에피소드 종료 시 팀 return을 받아 SMA로 평활화하고, EMV로 최근 변화량을 양의 신호로 바꾼 뒤, KSWIN으로 최근 구간과 이전 구간의 분포 차이를 판정한다. 논문 Table 1-2는 raw return에 KSWIN을 직접 적용하면 두 시나리오 모두 1/3 run만 검출하는 반면, PPR은 반복 알람을 줄이면서 shift를 식별하는 더 균형 잡힌 결과를 보였음을 보여준다.

**적용 지점** — 다중 에피소드 학습/평가 루프의 외부 보상 스트림 모니터링 단계

**기대 효과** — Raw return + KSWIN 대비 검출 누락 위험을 줄이고, SMA + KSWIN 대비 사전·사후 반복 알람을 크게 감소

### No-shift 기준선을 이용한 변화 감지기 오알람 검증 게이트

논문 Figure 2는 shift run과 matched no-shift run의 학습 곡선을 비교해 실제 변화가 return에 어떻게 드러나는지 확인한다. 이 절차를 일반화해 변화 감지기를 배포하기 전 no-shift 로그에서 알람 빈도를 측정하고, 사전 알람이 너무 많은 설정을 차단할 수 있다. SMA+KSWIN의 Table 1 사전 알람 298.3회는 이런 게이트가 필요한 대표 사례다.

**적용 지점** — 변화 감지/모니터링 컴포넌트의 배포 전 품질 검증 단계

**기대 효과** — 빠르지만 반복 알람이 많은 감지기 설정을 배포 전 걸러 운영 알람 노이즈를 줄임

### Replay 기반 자동 파라미터 캘리브레이션

논문 Table 3은 β=0.5가 detection delay를 141.7 ± 86.7로 줄이는 대신 사전 알람 44.3 ± 4.7회와 사후 알람 43.0 ± 2.6회를 만들고, β=1.0은 0/3 검출로 실패함을 보여준다. 운영 전 replay 또는 과거 학습 로그에서 후보 설정을 sweep하고, 사전 알람 상한을 만족하는 조합 중 지연이 짧은 값을 고르는 자동 튜닝 단계를 둘 수 있다.

**적용 지점** — 학습 시작 직전 파라미터 자동 캘리브레이션 단계

**기대 효과** — β=1.0의 0/3 검출 실패 같은 설정을 피하고, 낮은 지연과 낮은 반복 알람 사이의 균형점을 도메인별로 선택

## 단계별 도입 로드맵

| 단계 | 목표 | 액션 | 기대 효과 |
|---|---|---|---|
| Phase 1 | PPR 프로토타입 구현 및 오프라인 재현 검증 | 논문 Section 3의 SMA → EMV → KSWIN 파이프라인을 구현하고, MPE/PettingZoo 계열 Speaker-Listener 환경에서 reward-function-change와 landmark-colour-change를 재현한다. 원문 설정 w=8, β=2/3, α=2×10^-4, W=25, m=10을 기준으로 시작하고 seed 수를 늘려 지연·사전 알람·사후 반복 알람의 분포를 확인한다. | 논문 수치가 더 많은 seed에서도 유지되는지 확인하고, 배포 전 감지기의 기본 안정성을 검증한다. |
| Phase 2 | 온라인 MARL 훈련 루프에 외부 감시자로 결합 | MADDPG 또는 다른 MARL 학습기의 episode return 로그를 PPR에 연결한다. 변화 감지 시점, shift 이후 첫 알람, 반복 알람을 별도 이벤트로 기록하고 학습 곡선과 함께 시각화한다. | 학습 알고리즘을 직접 바꾸지 않고도 비정상성 감시 신호를 얻을 수 있다. |
| Phase 3 | 감지 신호와 적응 정책 연결 | PPR 알람이 발생했을 때 replay buffer 사용 조정, exploration 증가, critic 재초기화, 재학습 트리거 같은 후속 적응 액션을 실험한다. 단일 알람보다 연속 알람 또는 쿨다운 정책을 두어 반복 알람의 운영 부담을 줄인다. | 논문의 감지-only 한계를 넘어, 실제 변화 이후 학습 복구까지 평가할 수 있다. |
