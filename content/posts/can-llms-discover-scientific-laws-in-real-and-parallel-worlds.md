AI가 실제 과학 데이터를 보고 자연 법칙을 찾아낼 수 있는지, 이미 외운 공식을 말하는 것과 구분해서 평가하는 새 시험지를 만들었다.

**무엇이 문제였나** — 기존 시험지는 유명 공식을 외운 AI도 잘하는 것처럼 보일 수 있다는 문제가 있었다.
**어떻게 풀었나** — 이 논문은 118개의 실제 과학 문제, 381편의 논문, 약 800만 개 데이터 포인트를 모아 실제 관측 데이터를 보는 시험과 직접 실험값을 물어보는 시험을 함께 만들었다.
**그래서 뭐가 좋아졌나** — 결과적으로 AI는 데이터에 맞는 식을 찾을 때도 있지만, 그 식이 과학적으로 말이 되는지 판단하거나 여러 후보 중 좋은 답을 고르는 데는 아직 약했다.

> 학생이 실험 결과표를 보고 공식을 쓰는 상황과 비슷하다. 답이 숫자에는 맞아도 말이 안 되는 공식일 수 있고, 반대로 유명한 공식을 외워 썼을 뿐 새로 찾아낸 것이 아닐 수도 있다. 이 시험지는 숫자 맞춤, 과학적으로 말이 되는지, 새 구조를 찾았는지를 따로 채점한다.

## 논문 정보

Yiming Huang, Ziche Liu, Zhuohang Wu, Yiqian Wang, Junxia Cui, Xinkai Zou, Lingjun Mao, Nan Huang, Naicheng Yu, Kaijie Zhu, Yue Ma, Kun Zhou, Letian Peng, Jingbo Shang · University of California San Diego; University of California, Irvine; Cushing Academy; University of California, Santa Barbara · arXiv preprint (2609.01552v1) · 2026

## 왜 중요한가

AI가 과학 연구를 도울 수 있는지 판단하려면 단순히 숫자를 잘 맞히는지만 보면 부족하다. 실제 연구에서는 식이 데이터에 맞아야 할 뿐 아니라, 물리적 제약과 과학적 의미도 지켜야 하며, 이미 알려진 공식을 외운 답인지도 구분해야 한다.

## 핵심 지표

| 지표 | 값 | 설명 |
|---|---|---|
| 최고 모델 적합도 SN | **50.77%** | GPT-5.5의 SCILAWS-REAL 전체 평균 (최하위 GPT-4o-mini 20.59% 대비) |
| 최고 모델 과학적 타당성 SV | **81.84%** | GPT-5.5의 SCILAWS-REAL 전체 평균 |
| 최고 모델 구조 복원도 SS | **58.26%** | GPT-5.5의 SCILAWS-PARALLEL 전체 평균 |
| Best-of-N 자기선택 vs 오라클 격차 (N=20, SN) | **0.4286 vs 0.5549** | GPT-5.4-mini의 자기선택 0.4286, 오라클 최댓값 0.5549, 격차 +0.126 |

## 어떻게 동작하나

저자들은 381편의 과학 논문, 291개의 후보 법칙, 약 800만 개의 실측 데이터 포인트를 수집해 118개 SCILAWS-BENCH 문제를 만들었다. SCILAWS-REAL은 고정된 실제 관측 데이터에서 닫힌형 수식을 제안하게 하며, 단일 그룹 과제 66개와 다중 그룹 과제 52개로 구성된다. 단일 그룹은 문헌 근거에 맞춘 보간, 외삽, 시간 이전, 조건 이전 분할을 쓰고, 다중 그룹은 보지 못한 그룹에서 일부 구간으로 지역 파라미터를 맞춘 뒤 다른 구간에서 평가한다. SCILAWS-PARALLEL은 같은 과학 맥락을 유지하되, 출판 공식에서 구조적으로 변형한 숨겨진 법칙과 실제 잔차를 보정한 시뮬레이터를 만들고 모델이 능동적으로 입력값을 골라 관측값을 받아야 한다. 모든 모델은 같은 ReAct 스타일 에이전트 프레임워크, 파이썬 샌드박스, 최대 30턴 조건에서 평가되며, PARALLEL에서는 최대 10회 experiment 호출이 허용된다. SN은 닫힌형 계산으로 산출하고, SV와 SS는 gpt-5.4-mini 코드 실행 judge가 평가하며, cold-recall 판정은 gpt-4.1 judge를 사용한다. 다섯 명의 전문가 검증에서 Cohen's κ는 memorization 0.77, validity 0.82, structure 0.84였다.

핵심 수식:

```
SN(t) = clip(1 - (1/2)·(msub/mref), 0, 1)   [rmse, smape, log_mae]
SN(t) = clip(0.5 + (1/2)·(msub - mref)/(1 - mref), 0, 1)   [r2]
SV(t) = at · (Mt / Nt)
```

msub는 제출식의 원시 평가값, mref는 같은 과제에서 가장 강한 출판 공식의 원시 평가값이다. rmse, smape, log_mae는 낮을수록 좋고 r2는 높을수록 좋다. 가장 강한 출판 공식은 SN=0.5, 완벽한 예측은 SN=1.0을 받는다. at는 anti-hacking 게이트로 통과하면 1, 실패하면 0이다. Mt는 만족한 타당성 루브릭 항목 수, Nt는 전체 루브릭 항목 수다.

## 한계와 주의할 점

- 평가의 일부 핵심 채널(SV, SS, cold-recall 판정)을 LLM judge에 의존한다. 다섯 명의 전문가 검증에서 κ=0.77~0.84로 인간 간 일치 범위 안에 들지만, judge의 체계적 편향 가능성은 남는다.
- 에이전트 예산이 최대 30턴과 PARALLEL 최대 10회 experiment 호출로 제한되어, 실제 과학자가 장기간 수행하는 탐색과는 규모가 다르다.
- 벤치마크는 천문, 물리·지구, 소재·공학, 생물, 생태·수문, 사회과학의 6개 분야에 한정되어 있어 다른 분야로의 일반화는 추가 검증이 필요하다.
- 다중 그룹 과제는 그룹별 관측치와 문헌 근거가 충분해야 하므로, 데이터가 잘 정리된 분야에 더 많이 포함될 수 있다.
- 상위 평가 모델과 judge 모델이 최신 상용 모델을 포함하므로, 비용과 접근성 측면에서 모든 연구자가 즉시 동일 조건을 재현하기는 어렵다.
- 고적합-저타당 모드: 데이터를 잘 맞추는 수식을 제출하지만, 물리적으로 존재하지 않는 공명 피크처럼 과학적으로 말이 안 되는 구조를 넣어 타당성 검사에서 탈락한다.
- 암기-복사 모드: Canon 티어 과제에서 잘 알려진 공식을 기억해 베이스라인과 비슷한 성능은 내지만, 더 나은 새로운 식을 제안하지 못한다.
- 신규 구조 미발견 모드: SCILAWS-PARALLEL에서 출판된 기본 형태는 복원해도 합성된 추가 항은 놓치는 경우가 많다. 논문은 full-law recovery가 티어 전반에서 약 0.08 수준에 머문다고 보고한다.
- 자기선택 실패 모드: Best-of-N 후보 풀 안에 더 좋은 후보가 있는데도 선택하지 못한다. 5개 후보 그룹의 자기선택 승자 중 60%는 다른 후보에게 패레토 지배되며, 전체 20개 후보 풀에서 self-selected winner가 패레토 전선 위에 있는 비율은 12.7%뿐이다.

## 시스템 적용 아이디어

논문의 기법을 비슷한 구조를 가진 시스템에 옮길 때의 적용 지점이다.

### 에이전트 후보 풀의 패레토 인지 선택기 도입

논문의 Best-of-N 분석은 후보 풀이 커질수록 더 좋은 법칙이 나오지만, 모델이 이를 잘 고르지 못한다는 점을 보였다. 특히 5개 후보 그룹의 자기선택 승자 중 60%가 다른 후보에게 패레토 지배되었고, 20개 후보 풀에서 self-selected winner가 패레토 전선 위에 있는 비율은 12.7%였다. 이를 이용해 후보 생성 이후 각 후보를 다중 지표로 평가하고, 패레토 지배 후보를 제거한 뒤 최종 선택을 수행하는 하네스를 만들 수 있다.

**적용 지점** — 에이전트의 후보 답안 선택 단계

**기대 효과** — 원문 기준 N=20에서 self-selection SN 0.4286 vs oracle 0.5549, SV 0.7737 vs oracle 0.9306의 격차가 있어 선택기 개선 여지가 크다.

### 생성-검증 루프에 적합도/타당성 이중 채널 평가 삽입

논문은 fit-validity concordance가 54.9%에 그쳐, 높은 적합도가 높은 과학적 타당성을 보장하지 않는다고 보고한다. 따라서 수식 생성, 코드 생성, RAG 답변 등에서도 정답률 또는 테스트 통과율과 별도로 구조적 타당성 루브릭을 둬야 한다. lookup table, 과도한 상수, 데이터 암기성 코드 등을 막는 anti-hacking 게이트도 함께 적용할 수 있다.

**적용 지점** — 에이전트의 자기검증·품질 게이트 단계

**기대 효과** — 원문에서 확인된 high fit-low validity 문제를 별도 타당성 채널로 탐지할 수 있다.

### 실 데이터에 보정된 능동 평가 시뮬레이터 구축

SCILAWS-PARALLEL은 출판 공식에서 구조 변형을 만들고, 실제 데이터 잔차를 debias한 뒤 k-NN bootstrap으로 지역 노이즈를 샘플링하며, 필요할 때만 노이즈를 줄여 식별 가능한 세계를 만든다. 이 절차를 사내 실험 데이터에 적용하면 에이전트가 어떤 입력을 측정할지 고르고 숨은 구조를 찾는 능력을 평가할 수 있다.

**적용 지점** — 능동 학습 에이전트의 도메인별 평가 환경

**기대 효과** — 원문에서 full-law recovery가 낮게 나타난 추가 구조 발견 능력을 도메인별로 정량 평가할 수 있다.

### 암기 티어 분해로 진짜 추론 능력 진단

논문은 118개 과제 중 Canon 14개, Mid 48개, Moat 56개로 나누고, GPT-5.5의 > Ref%가 Canon 21%에서 Moat 54%로 올라간다고 보고한다. 내부 평가에서도 데이터 노출 가능성이나 cold-recall probe를 이용해 문제를 나누면, 새 모델이 단순히 더 많이 외운 것인지 실제로 새로운 문제를 더 잘 푸는지 구분할 수 있다.

**적용 지점** — LLM의 기억 회수와 데이터 기반 추론 능력 분리 평가

**기대 효과** — 원문 기준 Canon과 Moat에서 베이스라인 초과 비율이 크게 달라져, 모델 개선 원인을 분해해 볼 수 있다.

## 단계별 도입 로드맵

| 단계 | 목표 | 액션 | 기대 효과 |
|---|---|---|---|
| Phase 1 (0~3개월) | SCILAWS-BENCH 평가 인프라 내재화 및 자사 모델 기준선 확보 | 공개 데이터셋과 평가 스크립트가 제공되면 SN/SV/SS 산출 절차를 재현하고, 자사 모델 또는 후보 모델 3~5종을 같은 하네스에서 평가한다. LLM judge 결과는 표본 과제에 대해 전문가 또는 별도 judge로 교차 확인한다. | 신규 모델 도입 시 적합도, 과학적 타당성, 구조 복원도를 분리 비교할 수 있는 기준선을 확보한다. |
| Phase 2 (3~9개월) | Best-of-N 후보 선택 병목 개선 | 여러 후보 수식을 생성한 뒤 SN과 SV를 동시에 고려하는 선택기를 붙이고, 패레토 지배 후보를 걸러내는 평가 루프를 만든다. 논문에서 보고된 N=20 자기선택 SN 0.4286 vs 오라클 0.5549, SV 0.7737 vs 0.9306 격차를 내부 하네스에서 추적한다. | 후보 생성 능력이 이미 있는 에이전트에서 최종 선택 품질을 개선해 오라클과의 격차를 줄일 수 있다. |
| Phase 3 (9~18개월) | 도메인 특화 능동 평가 시뮬레이터 구축 | 사내 실험 데이터로 숨겨진 구조와 잔차 보정 노이즈를 가진 queryable world를 구축한다. 원문처럼 실제 입력 범위, 그룹 구조, 잔차 공간, 하향 노이즈 보정 조건을 명시해 평가 환경을 만든다. | 모델이 기존 데이터에 맞추는지, 직접 실험 조건을 골라 새 구조를 찾는지 도메인별로 측정할 수 있다. |
