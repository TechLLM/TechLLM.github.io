**한눈에 보기**
- 지난 1년간 코딩 에이전트 등 단일 작업 에이전트는 도구를 활용해 복잡한 문제를 풀면서 사람의 연속 모니터링과 단계별 개입 수요를 낮췄다.
- 모델의 다중 에이전트 조율 능력이 나아져 세션을 넘는 작업 조직과 스케줄링이 실용적 수준에 올라왔다.
- 사람의 역할은 실행 참여 비중이 줄며 고수준 의사결정과 승인 쪽으로 이동 중이다.
- 최근에는 메신저·캘린더·이메일에 직접 연결되는 개인 에이전트가 다수 등장했다.
- 원문 인용은 중간에 잘려 있어 이후 내용은 전문 확인이 필요하다.

## 도구를 쓰는 에이전트, 감시 없이 돌아가는 1년

X 계정 DeepSeek Harness가 'Exploring Super-agent Design: Towards a More Autonomous Agent System' 제목의 글을 게시했다. 여기서 에이전트는 언어모델이 스스로 도구를 호출하며 작업을 수행하는 소프트웨어를 가리키고, 단일 작업 에이전트는 하나의 목적에 특화된 에이전트를 뜻한다. 글의 첫 관찰은 지난 1년간 코딩 에이전트를 비롯한 단일 작업 에이전트가 복잡한 문제를 도구로 해결해 왔다는 사실이다.

성능보다 무거운 신호는 개입 방식의 변화다. 문제 해결 과정에서 사람의 **연속 모니터링**과 단계별 개입 필요성이 점점 줄었다는 것이다. 매 단계를 지켜보지 않아도 결과가 나오는 경험이 쌓이면 맡기는 작업 단위도 하나에서 묶음으로 커질 여지가 생긴다.

코딩 영역이 앞선 이유도 짚을 만하다. 결과 검증이 상대적으로 기계적으로 가능한 분야라 자율 실행의 첫 사례가 되기 쉬웠다는 해석이 가능하다.

## 세션을 넘는 조율, 슈퍼 에이전트 논의의 출발점

두 번째 관찰은 협업 능력이다. 글에 따르면 모델은 여러 에이전트를 조율하는 능력도 나아졌고, 이 덕분에 세션을 넘어 작업을 조직하고 스케줄링하는 방식이 실용적이 됐다. 세션은 하나의 대화·작업 단위를 뜻하므로 세션을 넘는다는 말은 대화가 끊겨도 작업 맥락이 이어진다는 뜻이다.

이 지점이 제목의 **슈퍼 에이전트** 개념과 닿는다. 여러 에이전트 위에서 작업을 배분하고 조율하는 상위 구조로 읽히는 개념이며, 제목의 '더 자율적인 에이전트 시스템'이라는 표현도 같은 방향을 가리킨다. 개별 에이전트의 세부 동작 대신 전체 작업 배치를 관리하는 층이 생기면 운영 부담은 사람에서 시스템으로 옮겨간다.

## 사람은 실행 대신 고수준 결정과 승인으로

글의 결론은 역할 재배치다. 사람이 저수준 실행에 참여하는 비중이 줄수록 역할은 고수준 의사결정과 승인으로 이동한다. 승인(사인오프)은 에이전트가 낸 결과를 사람이 최종 확인하고 허가하는 절차를 말한다.

| 구분 | 이전 | 바뀌는 방향 |
|---|---|---|
| 사람 개입 | 연속 모니터링과 단계별 개입 | 개입 필요성 지속 감소 |
| 담당 층위 | 저수준 실행 | 고수준 의사결정과 승인 |
| 작업 단위 | 세션 안에서 끝나는 실행 | 세션을 넘는 조직과 스케줄링 |

오른쪽 열은 글이 진행형으로 표현한 변화다. 완료된 전환으로 읽기보다 흐름으로 이해하는 편이 정확하다.

실행을 맡긴 뒤에도 판단은 사람 몫으로 남는다. 자율성이 커질수록 어디서 무엇을 승인할지 설계하는 일이 오히려 중요해진다.

## 일상 서비스로 확장되는 개인 에이전트

글은 성능 향상이 새 응용을 만들었다고 덧붙인다. 최근 다수의 개인 에이전트가 등장해 메신저, 캘린더, 이메일 같은 일상 서비스에 직접 연결된다. 개인 에이전트는 사용자의 일정·대화·메일을 대신 다루는 에이전트로, 코딩에서 검증된 패턴이 일상 업무로 넓어지는 국면이다.

| 구분 | 코딩 등 단일 작업 에이전트 | 개인 에이전트 |
|---|---|---|
| 주무대 | 개발 작업 | 메신저·캘린더·이메일 등 일상 서비스 |
| 입증 지점 | 도구 활용 문제 해결과 개입 수요 감소 | 일상 서비스 직접 연결 |
| 시점 | 지난 1년간 | 최근 |

한 가지 한계도 짚어둔다. 공개된 원문 인용은 일상 서비스 열거에서 잘려 있고 슈퍼 에이전트의 구체 설계도 인용 범위 안에 없다. 세부 구조와 이후 주장은 전문을 직접 확인해야 한다.

## 그래서 무엇이 달라지나

인용 범위에서 확인되는 변화를 먼저 나열한다. 모두 글이 명시한 내용이다.

- 에이전트 실행에 필요한 사람 개입이 줄었다.
- 다중 에이전트 조율이 실용적 수준에 도달했다.
- 개인 에이전트가 일상 서비스에 진입했다.

이후 전개는 추측임을 밝혀둔다. 승인 중심 역할이 자리 잡으면 결과 검토와 기록을 돕는 도구와 절차의 수요가 커질 가능성이 있다. 개인 에이전트가 메신저와 이메일 권한을 다루는 만큼 접근 통제와 책임 소재가 과제로 떠오를 수도 있다.

조직 차원에서는 에이전트 관리를 전담하는 역할이 생길 가능성도 있다. 다만 슈퍼 에이전트의 실제 구조는 잘린 인용만으로는 판단할 수 없다.

## 정리

이 글은 에이전트 발전사를 사람 개입 축소라는 잣대로 정리한 실무 로드맵이다. 개인 에이전트까지 등장한 지금 남는 질문은 얼마나 자율을 줄지가 아니라 어디서 승인할지다. 전체 설계의 세부는 잘린 인용 탓에 원문 확인이 필요하다.
